How to use MyTiffin

Short, step-by-step guides for tiffin providers and for customers. Pick where you are.

For tiffin providers

Quick start: your first day

About ten minutes. You only do steps 1 to 3 once.

  1. Create your account

    Go to Get started, choose Tiffin provider, and enter your service name, phone number and a password (6+ characters). You stay logged in on that phone for 30 days.

  2. Add your customers

    Open Customers → Add customer. Fill in name, phone, address, Normal or Deluxe, and how many boxes per day. Use Note for kitchen for things like “less spicy”. Under More options you can set a start date, or a last day when someone stops.

  3. Set up your business

    In Settings add your phone, your price per box (optional, used for reports), and any weekday you are closed, such as Sunday.

  4. Every morning: open Today

    The big number is how many boxes to prepare, split into Normal and Deluxe. Use the arrows to see tomorrow. Customers on leave are already taken out.

  5. Tick deliveries as you go

    Tap Delivered ✓ on each customer. Use Call and Map if you need them. Tapped by mistake? Open the Delivered tab and press Undo. The bar shows how many are left.

  6. Handle leave

    Customers can mark their own leave (see how they connect). To add one yourself, open the customer and use Leave / holiday: pick the first and last day, then Add leave. Remove it with the ✕.

  7. Closing for a holiday

    In Settings → Closing for a holiday? pick the first and last day and add a note. No tiffin is counted on those days and every customer with a Telegram login is told. Remove it to tell them you will deliver after all.

  8. Month end: Reports

    Open Reports to see delivered days, leave days and amount per customer. Share each customer’s summary on Telegram, or download a spreadsheet.

  9. Get found: Grow

    In Grow, switch on your marketplace listing so nearby customers can find you. New join requests appear there, and you can add them as customers in one tap. Advertising is optional.

Stuck? Read the troubleshooting section, or the blog for tips on leave policy, pricing and billing.

Telegram alerts

Connect Telegram in five steps

Optional, but very useful: you hear about a customer’s leave the moment it happens.

What you will get

Leave alertsInstantly when a customer marks or cancels leave, with tomorrow’s updated box count.
Morning summaryBoxes to cook today, and who is on leave. Default time 7:00.
Evening summaryTomorrow’s count, in time to plan shopping. Default time 20:00.
New requestsWhen someone asks to join from the marketplace.
Commands/today /tomorrow /pending (who is still waiting for delivery)

Connect your Telegram

  1. Install Telegram

    Get the free Telegram app on your phone and sign in.

  2. Find your code

    In MyTiffin open Settings → Telegram alerts. You will see the bot ({{BOT_AT}}) and your personal connect code.

  3. Open the bot

    In Telegram, search for {{BOT_AT}} (or open it directly), open it and tap Start.

  4. Send your code

    Type /start, a space, then your code. Example: /start ABCD2345

  5. Check it works

    The bot says you are connected. Back in the app, press Send test. You can change the morning and evening times in the same place, or clear a time to turn that summary off.

Use a private chat with the bot (not a group). Your code links the chat to your kitchen only, so other providers on the same bot never see your customers. If the bot can, it deletes your code message after connecting.

The bot says “That code is not right”

Copy the code again from Settings → Telegram alerts. Codes are not case-sensitive. If you pressed Disconnect earlier, the code changed, so use the new one. After 5 wrong tries the bot waits an hour before accepting codes from that chat.

The bot does not answer at all

The person who runs the system may not have switched Telegram on yet. In Settings you would see “Telegram alerts are not switched on yet”. Send them the section below.

I changed my phone or Telegram account

In Settings → Telegram alerts press Disconnect, then connect again from the new phone with the new code.

For whoever runs the system (one-time setup)

One bot serves every provider. You create it once.

  1. Create the bot

    In Telegram, open @BotFather and send /newbot. Choose any display name. The username must end in bot (this site uses {{BOT_AT}}). BotFather replies with a token.

  2. Keep the token secret

    Anyone with the token can control the bot. Do not share it or put it in the website code or a public repository.

  3. Give it to the server

    Start the app with the token in the environment: TELEGRAM_BOT_TOKEN=your-token npm start. On a hosting service, add it as an environment variable and restart.

  4. Confirm it is running

    The server log shows [telegram] bot @your_bot_username ready. Providers will now see the bot name and their connect code in Settings.

  5. Optional: polish the bot

    In BotFather you can set a profile picture and description (/setuserpic, /setdescription) and a command list (/setcommands): today, tomorrow, pending.

Troubleshooting the server side

“getMe failed” in the log: the token is wrong or has extra spaces. Create a new one in BotFather with /token and update the variable.

Network errors: the server must be able to reach api.telegram.org over HTTPS. Some hosts restrict outgoing connections.

Run only one copy: the bot listens by polling. If two copies of the app use the same token at the same time, they fight and Telegram reports a conflict. Keep a single instance, or stop the old one first.

Timing: summaries follow the server’s TZ setting (default Asia/Kolkata). Set it to your own timezone.

For customers

Using MyTiffin as a customer

It is free for you. You can log in, or just use a personal link your provider sends.

Mark your leave

  1. Get access

    Either open the personal link your provider sent you (no password needed), or create a login with the phone number your provider saved for you, the 6-digit sign-up code they give you (it proves the number is yours), and a password. If you open your personal link, tap Create a login there and no code is needed.

  2. Pick your days

    Choose the first and last day you do not need tiffin, then tap Mark my leave. Your provider’s box count updates and they get an alert.

  3. Changed your mind?

    Under Your leaves, tap Cancel. A leave that has not started is removed. If it is already running, only the remaining days are cancelled and the days already gone stay as leave. For anything urgent or same-day, please call your provider.

  4. A provider added you

    If you already have a login and a new provider adds your number, you see Accept and Not mine on My tiffin (and in Telegram if connected). Until you accept you are not counted in their boxes. Not mine tells them the number is not yours.

  5. Rate your provider

    After about a week with a provider you can open Rate this service, give 1–5 stars and a few words. You can change it any time. Your first name and comment show on the marketplace. A provider can reply, and the MyTiffin team can hide unfair or abusive reviews.

  6. When your provider closes for a holiday

    You are told on Telegram (if connected) and the closed days show on your page. No tiffin is counted on those days.

  7. Use more than one provider?

    If two providers have added your number, you see both on My tiffin. Mark leave with one, or use Mark leave for all to skip every service at once. You are never tied to a single provider.

  8. Switch to another provider

    On My tiffin tap Switch to another provider, search, and choose Switch to this one with a start date. Services you already have are marked. Your current provider stops the day before your start date, but only once the new provider accepts, so you are never left without a tiffin. Waiting requests show under Waiting for a reply and you can cancel them.

  9. Stop with a provider

    Open Stop with this provider on that service and pick your last day. The provider is told on Telegram. Changed your mind? Tap Undo before the last day passes. Stopped services move to Past tiffin services.

By default you can mark leave from tomorrow onwards. Some providers allow same-day changes until a set hour. If your date is not accepted, you will see the earliest allowed date.

Find a new tiffin service

  1. Search

    Open Find tiffin. Tap Use my current location, or type your pincode or address. You do not need an account.

  2. Compare

    Results are nearest first. You see the food type, meals, price and approximate distance. A Sponsored label means the provider paid for a top spot. Sponsored places are only shown to people near them.

  3. Contact or join

    Call them, or tap Request to join and send your name, phone and address. Your details go only to that provider.

It says my phone number was not found

You can only create a login with a number your provider has added. Ask them to add or correct it. Numbers are matched on the last 10 digits, so the country code does not matter.

I forgot my password (customers)
  1. Open the forgot password page and choose Customer.
  2. Enter your phone number and tap Send code to my Telegram.
  3. Open Telegram. {{BOT_AT}} sends you a 6-digit code (valid for 10 minutes).
  4. Type the code, choose a new password and log in.

This works only if you connected Telegram earlier on your My tiffin page (Telegram, then send /start and your code to the bot). If you did not, see the next question.

Tiffin providers: contact support (the contact is shown on the forgot password page). After checking it is you, they send a one-time reset link. Then connect Telegram in Settings → Telegram alerts so you can reset it yourself next time.

Customers: ask your tiffin provider. They open your name in their MyTiffin app, tap Create reset link and send it to you on Telegram. Open the link and choose a new password. It works once and expires in 24 hours. (If you use more than one tiffin service, contact support instead.)

I use more than one tiffin service

If each saved your number, your login shows all of them as separate cards, each with its own leave.

Providers and customers together

How the two sides connect

One simple loop keeps everyone informed.

  1. Customer finds you

    They search in the marketplace, or you simply tell them about your service.

  2. You add them

    A join request lands in Grow. Tap Add as customer, or add them yourself with their phone number. Unanswered requests get a Telegram reminder after a day. If you add someone who already has a login, they are asked to confirm you first.

  3. You share access

    Open the customer and tap Telegram to share their personal leave link (or Copy it), or give them the 6-digit sign-up code shown on their customer page so they can create a login with their phone number.

  4. Customer marks leave

    From their phone, in seconds.

  5. You are told

    Instant Telegram message and your Today count updates. Nothing to chase.

  6. You deliver, tick, and bill

    Deliveries and leave days feed your monthly report, so the bill matches what both of you saw.

ProviderAdds customers · sees today’s count · ticks deliveries · reads reports · gets Telegram alerts · lists in the marketplace
CustomerMarks and cancels own leave · sees today’s status · searches for services · requests to join
BothLog in with phone number and password · stay logged in for 30 days · change password any time
Locked out?

Forgot your password?

Your account is tied to your phone number, so we check it is really you before changing anything.

Tiffin providers: a code on Telegram

  1. Ask for a code

    On the login page tap Forgot password? and enter your phone number. We send a 6-digit code to the Telegram chat you connected (Settings → Telegram alerts).

  2. Choose a new password

    Type the code and your new password (6+ characters). The code works for 10 minutes and allows 5 tries. You are signed out on all other phones.

Connect Telegram now, before you need it. It is also how you recover your account. If it is not connected, the code cannot be sent. Contact support (below) for a reset link.

Customers: a code on Telegram, or a link from your provider

Best, once: connect Telegram. Then you can reset your password yourself.

  1. Connect Telegram (do this now, while you can log in)

    On your My tiffin page open Telegram (optional). Open {{BOT_AT}}, tap Start, send /start and the code shown, then tap I did it.

  2. Forgot it later? Ask for a code

    On the forgot password page choose Customer, enter your phone number and we send a 6-digit code to that Telegram chat. It works for 10 minutes and allows 5 tries.

No Telegram? Ask your tiffin provider. They open your name in their MyTiffin app, tap Create reset link and send it to you on Telegram. The link works once and expires in 24 hours. If you use more than one tiffin service, a single provider cannot reset your login, so contact support instead. Your personal leave link keeps working without a password.

Anyone: contact support

Support can create a one-time reset link after checking it is you (for example by calling or messaging you from the phone number on the account). The support contact is shown on the forgot password page.

Troubleshooting

Common questions

The count on Today looks wrong

Check that the customer’s start date and last day (More options) are right, that closed weekdays in Settings are correct, and whether they have leave on that date. Boxes per day also multiplies the count.

I marked Delivered by mistake

Open the Delivered tab on Today and press Undo.

How do I reset my password? (tiffin providers)
  1. On the login page tap Forgot password? (or open mytiffin.online/forgot).
  2. Enter your phone number and tap Send code to my Telegram.
  3. Open Telegram. {{BOT_AT}} sends you a 6-digit code. It works for 10 minutes.
  4. Type the code, choose a new password (6+ characters) and tap Set new password.
  5. Log in with the new password. You are signed out on your other phones.

No code arrives? Telegram is probably not connected for this number. See “I never connected Telegram” below.

How do I reset my password? (customers)
  1. Open the forgot password page and choose Customer.
  2. Enter your phone number and tap Send code to my Telegram.
  3. Open Telegram. {{BOT_AT}} sends you a 6-digit code (valid for 10 minutes).
  4. Type the code, choose a new password and log in.

This works only if you connected Telegram earlier on your My tiffin page (Telegram, then send /start and your code to the bot). If you did not, see the next question.

I never connected Telegram. Can I still get back in?

Tiffin providers: contact support (the contact is shown on the forgot password page). After checking it is you, they send a one-time reset link. Then connect Telegram in Settings → Telegram alerts so you can reset it yourself next time.

Customers: ask your tiffin provider. They open your name in their MyTiffin app, tap Create reset link and send it to you on Telegram. Open the link and choose a new password. It works once and expires in 24 hours. (If you use more than one tiffin service, contact support instead.)

How do I change my password when I remember it?

Providers: Settings → Change password. Customers: My tiffin → Change password. Enter your current password and a new one. Your other phones are signed out.

I am not in the marketplace

In Grow, the listing switch must be on, and you need an area plus either a pincode or a set location. Press Save listing. A listing can also be hidden if it was suspended by the administrator.

Is my customers’ data private?

Each provider only sees their own customers. In the marketplace only a rough location (about 1 km) and the business details you choose are shown. A customer’s search location is not stored.
